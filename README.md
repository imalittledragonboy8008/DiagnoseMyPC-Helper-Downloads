# DiagnoseMyPC Windows helper downloads

This public repository hosts the unsigned Windows x64 helper ZIP for the DiagnoseMyPC supervised, personal pilot. [Download pilot build 0.1.0 pilot.2](https://github.com/imalittledragonboy8008/DiagnoseMyPC-Helper-Downloads/releases/tag/v0.1.0-pilot.2) and verify the SHA-256 shown on the release page and [the DiagnoseMyPC download page](https://diagnosemypc.vercel.app/helper).

The ZIP contains a one-time executable, not an installer or background service. No license key is required. The helper cannot upload results without a one-time code from a current website assessment. It is unsigned, so Windows may show an unknown-publisher warning. Keep Windows protections enabled and run it only if you trust the artifact and its checksum.

Hardware readings are limited by Windows providers. The helper does not certify hardware health or diagnostic accuracy across devices. The application source is maintained in a separate private repository during this pilot.
